# Upward Camera Homing Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a second homing camera aimed 70° above the nose, steer from the center of a square around the target, and stop the flight at the ground or at 20 seconds.

**Architecture:** `target_square` measures the full-resolution image. `HomingGuidance` chooses the forward or upward camera and emits the square it steered from. The runner renders both cameras and stores previews plus that square. The Plotly page draws both pictures, the square, and both frustums.

**Tech Stack:** Python >= 3.8, NumPy, SciPy `Rotation`, existing RotorPy `PinholeCamera`, `Multirotor`, `SE3Control`, Plotly, Pillow, pytest.

**Spec:** `docs/superpowers/specs/2026-10-23-upward-camera-homing-design.md`

## Global Constraints

- Python >= 3.8. Type hints use `typing.Optional` and `typing.Tuple`, not the `|` union syntax.
- Do not change proportional navigation, `desired_velocity`, the SE3 controller, the vehicle, or the world.
- Forward mount stays `pitched_extrinsics(10)`. Upward mount is `pitched_extrinsics(-70)`. Both camera positions stay `[0, 0, 0]`. Intrinsics stay 2236×2236, 90° by 90°.
- Lock threshold stays 36 target pixels. Target pixels stay `red > 0.5` and red strictly greater than green and blue.
- Sim rate stays 100 Hz. Both cameras render on the existing 20 Hz ticks, including t = 0.
- `flight_status(t, sim_z)` returns `"ground"` when `sim_z <= 0`, else `"timeout"` when `t >= 20`, else `None`. Ground is checked first. No speed stop. No 120 second stop.
- A ground stop is `miss_outcome`. A 20 second stop is `timeout_outcome`.

## Review Focus

- Pixels in the upward camera whose square center misses the ground latch that camera and do not permanently lose. A later nose-down frame from the upward camera steers. Tested in Task 3.
- An empty forward frame after steering does not block a later upward frame. Tested in Task 3.
- After the upward camera's pixel count drops below 36, neither camera steers again. Tested in Task 3.
- The first upward steering tick commands zero proportional-navigation acceleration even when the previous forward tick did not. Tested in Task 3.
- Simulator `z <= 0` stops an unlocked flight, `t >= 20` stops a locked flight, and a 20 m/s velocity component does not stop the flight. Tested in Task 4.

def test_square_center_steers_not_the_centroid():
    guidance = _guidance()
    image = np.zeros((32, 32, 3))
    image[20:26, 10:16, 0] = 1.0
    image[20, 20, 0] = 1.0
    command = guidance.update(0.0, 30.0, IDENTITY, _course(), image, np.zeros((32, 32, 3)))
    assert command.tracking is True and command.source == "forward"
    assert np.allclose(command.tracker_center, [15.0, 22.5])
    assert command.tracker_side == 11
    sightline = _sightline_ned(command.tracker_center, IDENTITY, INTRINSICS, pitched_extrinsics(10.0))
    expected = desired_velocity(ground_relative_position(30.0, sightline))
    assert np.allclose(command.velocity_ned, expected)

def test_upward_latch_survives_a_skyward_sightline_then_steers_nose_down():
    guidance = _guidance()
    black = np.zeros((32, 32, 3))
    blob = _blob(13, 13)
    nose_down = Rotation.from_euler("y", np.deg2rad(80.0)).as_quat()
    sky = guidance.update(0.0, 30.0, IDENTITY, _course(), black, blob)
    assert sky.locked is True and sky.tracking is False and sky.source is None
    assert np.allclose(sky.velocity_ned, _course())
    steered = guidance.update(0.05, 30.0, nose_down, _course(), black, blob)
    assert steered.tracking is True and steered.source == "upward"
    assert np.allclose(steered.acceleration_ned, 0.0)
    assert not np.allclose(steered.velocity_ned, _course())

def test_forward_loss_lets_the_upward_camera_steer_then_loss_sticks():
    guidance = _guidance()
    black = np.zeros((32, 32, 3))
    blob = _blob(13, 13)
    nose_down = Rotation.from_euler("y", np.deg2rad(80.0)).as_quat()
    first = guidance.update(0.0, 30.0, IDENTITY, _course(), blob, black)
    shifted = guidance.update(0.05, 30.0, IDENTITY, _course(), _blob(17, 13), black)
    assert shifted.tracking is True and not np.allclose(shifted.acceleration_ned, 0.0)
    coast = guidance.update(0.10, 30.0, IDENTITY, _course(), black, black)
    assert coast.tracking is False and coast.source is None
    assert np.allclose(coast.velocity_ned, shifted.velocity_ned)
    upward = guidance.update(0.15, 30.0, nose_down, _course(), blob, blob)
    assert upward.source == "upward" and upward.tracking is True
    assert np.allclose(upward.acceleration_ned, 0.0)
    lost = guidance.update(0.20, 30.0, nose_down, _course(), blob, black)
    assert lost.tracking is False and np.allclose(lost.velocity_ned, upward.velocity_ned)
    again = guidance.update(0.25, 30.0, nose_down, _course(), blob, blob)
    assert again.tracking is False and np.allclose(again.velocity_ned, lost.velocity_ned)
